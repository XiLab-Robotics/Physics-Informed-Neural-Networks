# Parallel Shape-Objective Follow-Up Campaign Plan

## Overview

This campaign plan prepares a small follow-up after the completed
`shape_gate_loss_v2` bounded screen. The prior v2 candidate is confirmed to be
a windowed `periodic_gru_sequence` model. It improved over the first
shape-gate pilot but did not beat the current forward recommendation or the
best non-windowed baseline in the bounded screen.

The campaign should test three distinct pilot directions in parallel and stop
quickly if none clears the bounded forward evidence gate.

## Candidate Arms

| Arm | Runtime Contract | Purpose |
| --- | --- | --- |
| `shape_objective_v3_periodic_gru_sequence_fw` | Windowed sequence | Stronger centered-shape, derivative, and harmonic amplitude/phase pressure on the existing temporal family. |
| `shape_objective_periodic_mlp_harmonic_fw` | Non-windowed point model | Direct comparison against the best non-windowed neural reference instead of only GRU-family comparisons. |
| `shape_objective_curve_aware_residual_fw` | Curve-aware residual model | Explore the robust/quantile-style backbone area that already outranked v2 in the bounded screen. |

## Acceptance Gates

The first promotion gate is a bounded forward screen, not a full matrix. A
candidate should continue only if it satisfies all of the following:

- Beats the previous v2 candidate on raw MAE and centered MAE.
- Beats or materially matches `polished_setpoints_periodic_mlp_harmonic_Fw`,
  the best non-windowed reference from the previous screen.
- Beats or materially matches `polished_setpoints_periodic_gru_sequence_Fw`,
  the current forward recommendation.
- Does not regress shape pass rate, offset behavior, or harmonic/phase
  evidence under the shape-gated reranker.

## Pilot Report Graphs

Every pilot results report in this follow-up should include graph evidence,
not only scalar tables. The minimum figure set is:

- Representative measured-versus-predicted TE curves for each surviving arm.
- Residual/error curves for the same representative conditions.
- Per-condition error distribution plots or heatmaps over speed, torque, and
  oil temperature.
- A compact comparison plot against
  `polished_setpoints_periodic_gru_sequence_Fw` and
  `polished_setpoints_periodic_mlp_harmonic_Fw`.

The figures should be generated by repository-owned scripts and referenced from
the Markdown campaign-results report before styled PDF export.

## Launch Policy

The launcher must support:

- `-PreflightOnly`
- `-RunOneBatchValidation`
- local execution
- `-Remote` execution through the repository-owned remote campaign workflow

The remote launch must sync source/configuration/docs before execution and
sync campaign outputs, per-run artifacts, queue end state, registries, and
status artifacts after completion.

## Decision Policy

This is a bounded exploration. If no arm beats the current non-windowed and
windowed references on the bounded forward screen, the branch should be closed
without full-surface expansion. If one arm clears the gate, it can be promoted
to a separate full `global` / `Fw` / `Bw` campaign plan.
