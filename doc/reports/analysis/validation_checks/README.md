# Validation Checks

This folder contains generated validation evidence and setup reports. It is
not the primary narrative-report surface.

## Directory Map

- `infrastructure/` contains infrastructure and tooling validation checks.
- `model_development_waves/` contains generated validation setup reports for
  model-development wave candidates.
- `rcim_model_bank_reproduction/` contains RCIM Model-Bank Reproduction
  validation outputs, including legacy `track1` machine identifiers where they
  belong to completed historical artifacts.
- `te_curve_verification_pipeline/` contains validation reports generated by
  TE Curve Verification Pipeline matrix refreshes.

Generated report filenames may remain long because they preserve run identity,
surface, family, and timestamp provenance.
