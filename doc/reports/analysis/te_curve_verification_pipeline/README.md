# TE Curve Verification Pipeline Reports

This folder contains official offline TE curve verification evidence and
decision material. It replaces the older `track2` analysis-report root while
preserving historical report filenames where they remain provenance-sensitive.

## Directory Map

- `00_overview/` contains the canonical directional comparison, curve
  reconstruction guide, and multi-index curve-first selection policy.
- `01_official_decisions/` contains dated official model-verification reports.
- `02_visual_reports/` contains collage, overlay, mean-centered visual reports,
  and future dataset/surface visual report bundles.
- `03_cvp_diagnostics/` contains CVP diagnostic reports, including curve-first
  reranking, curve-payload diagnostics, mean-offset audits, offset feasibility,
  and future dataset-difference diagnostics.
- `04_offset_investigations/` contains offset and component-identification
  investigations.
- `05_reference_and_legacy/` contains reference comparisons, original ONNX
  checks, sparse original variants, and legacy planning material.

Use `01_official_decisions/` for decisions and `02_visual_reports/` for visual
evidence. Do not infer official promotion status from scalar campaign metrics
alone.
