# Analysis Reports

This folder groups canonical analysis material by report domain rather than by
the historical order in which reports were produced.

## Directory Map

- `project_status/` contains maintained program-status ledgers, repository
  status synthesis reports, and dated project-status presentation bundles.
- `te_modeling/` contains analytical TE modeling, MMT equation extraction,
  TwinCAT-friendly modeling strategy, curve-first training strategy, and model
  family studies.
- `model_development_waves/` contains Wave `1` through Wave `5.2` model
  development reports and wave-local diagnostic bundles.
- `training_configuration/` contains training-configuration analysis reports.
- `te_curve_verification_pipeline/` contains the official offline TE curve
  verification reports, visual evidence bundles, CVP diagnostics, offset
  investigations, and reference or legacy comparison material.
- `validation_checks/` contains generated validation setup reports and
  historical validation-check outputs grouped by workflow.
- `rcim_paper_reference/`, `twincat_video_guides/`, `utilities/`, and other
  narrow roots contain topic-specific analysis material that already had a
  stable human-facing scope.

## Navigation Rules

- Start from `project_status/current/` for the current TE program status and
  repository status synthesis.
- Start from `te_curve_verification_pipeline/00_overview/` for the current TE
  Curve Verification Pipeline policy and canonical directional comparison.
- Use `te_curve_verification_pipeline/01_official_decisions/` for official
  model-verification decisions.
- Use `te_curve_verification_pipeline/02_visual_reports/` for collage and
  overlay evidence.
- Use `validation_checks/` for machine-generated validation evidence rather
  than narrative analysis.
