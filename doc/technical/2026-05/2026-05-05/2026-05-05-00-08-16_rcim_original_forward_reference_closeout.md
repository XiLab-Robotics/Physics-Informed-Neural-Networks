# RCIM Original Forward Reference Closeout

## Overview

This document plans the closeout of the completed RCIM original forward
reference bundle generated by:

- `output/training_campaigns/rcim_original/forward/2026-05-04-23-19-35__fw_original_bundle`

The closeout will promote the exported forward models from the campaign output
area into the curated archive under:

- `models/paper_reference/rcim_original/forward`

The archive layout must mirror the existing family-by-family structure already
used by:

- `models/paper_reference/rcim_track1/forward`

## Technical Approach

The implementation will treat the completed forward campaign bundle as the
source of truth for the exported model artifacts. The closeout pass will:

1. Inspect the exported Python and ONNX model files under the completed
   `export/model_output_dir` subtree.
2. Map the exported family folders to the canonical paper-reference archive
   family roots under `models/paper_reference/rcim_original/forward`.
3. Create the same family archive surface already used by
   `models/paper_reference/rcim_track1/forward`, including the expected
   `onnx/`, `python/`, `data/`, and `source_runs/` subtrees.
4. Copy the completed source-run bundle into the family archive provenance
   surface so the promoted reference models remain traceable to the originating
   forward campaign bundle.
5. Generate or update the archive-local inventory and README material required
   to make the new RCIM original forward reference archive self-describing.

The closeout will remain scoped to the completed forward RCIM original bundle.
It will not mutate the active RCIM Model-Bank Reproduction campaign state or the protected
`doc/running/active_training_campaign.yaml` surface.

## Involved Components

- `output/training_campaigns/rcim_original/forward/2026-05-04-23-19-35__fw_original_bundle`
- `models/paper_reference/rcim_original/forward`
- `models/paper_reference/rcim_track1/forward`
- `scripts/campaigns/paper_reference/rcim_original/`
- `scripts/paper_reimplementation/rcim_ml_compensation/recovered_original_workflow/`

## Implementation Steps

1. Audit the completed forward export bundle and enumerate the family-level
   exported artifacts.
2. Inspect one canonical `rcim_track1` family archive and reuse its structural
   contract for `rcim_original`.
3. Create the missing `rcim_original/forward/<family>_reference_models`
   directories.
4. Copy ONNX and Python model artifacts into the matching `onnx/` and
   `python/` archive subtrees.
5. Copy the dataset snapshot and source-run provenance material into the
   archive-local `data/` and `source_runs/` subtrees.
6. Generate the archive-local README and machine-readable inventory files for
   the promoted RCIM original forward reference models.
7. Update the relevant repository documentation indices that expose the new
   archive state.
8. Run Markdown QA on every touched repository-owned Markdown file before
   reporting completion.
