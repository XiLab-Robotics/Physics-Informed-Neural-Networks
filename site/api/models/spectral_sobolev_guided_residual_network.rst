Spectral And Sobolev Guided Residual Network
============================================

Wave 5.2R Stage 6 tests bounded coordinate residuals with raw circular
coordinates, frozen Fourier features, and sinusoidal representation networks.
Every branch reconstructs a complete periodic forward transmission-error curve
from causal setpoint inputs.

The completed Stage 6 campaign promoted no candidate. This API remains an
experimental, reproducible model surface and must not be interpreted as the
accepted production predictor.
