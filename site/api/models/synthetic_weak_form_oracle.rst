Synthetic Weak-Form Oracle
==========================

Wave 5.2R Stage 13 provides deterministic Fourier recovery, pointwise
oscillator residual, weak periodic-test residual, noise corruption, and
parameter-recovery utilities for synthetic certification.

Synthetic success validates implementation and observability only. It does not
establish that a mechanism is present in measured reducer data.
