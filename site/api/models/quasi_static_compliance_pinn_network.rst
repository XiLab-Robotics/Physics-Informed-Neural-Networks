Quasi-Static Compliance PINN Network
====================================

Wave 5.2 Phase 3 separates angularly periodic TE from a bounded quasi-static
elastic contribution. The family provides learned differential-residual and
hard equation-embedded formulations while preserving explicit signed torque,
effective stiffness, direction intercept, elastic prediction, and periodic
components.

The implementation is a bounded theory-validation surface. Fitted stiffness
must not be treated as a uniquely identified reducer property without the
campaign's held-out and initialization-stability evidence.
